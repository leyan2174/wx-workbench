# 开发与回归验证

## 构建

项目支持 Windows x64 MSVC。使用当前仓库源码和锁定依赖，不以另一份安装程序代替本次构建验证。

```powershell
cargo check --target x86_64-pc-windows-msvc
cargo test --target x86_64-pc-windows-msvc
cargo fmt --all -- --check
cargo clippy --all-targets --target x86_64-pc-windows-msvc -- -D warnings
```

可执行文件被占用时先核验所属任务，不能为完成构建按名称终止用户应用。可使用新的独立 target 目录，不覆盖仍在运行的构建产物。

## 按风险选择验证

- 参数或格式修改：覆盖合法输入、拒绝路径、退出码和输出契约。
- 账号、协议、进程和发布逻辑：验证跨账号隔离、取消、异常退出、限额及清理。
- 共享模块：检查主仓和包含该模块的夹具；重复执行的单元测试不等于独立功能数量。
- 界面：核对真实返回、错误展示、桌面和手机布局，不仅检查页面能打开。
- 文档：核对当前命令、源码链接、前置条件和发布内容，不记录每轮成绩。

完整基线与修复顺序见[测试与整理计划](testing-plan.md)。可选条件和真实账号规则见[测试说明](../tests/README.md)。

## 结果判定

分别记录通过、失败和条件未满足。需要人工登录、重启、补充凭据或新的下载/上传授权时跳过该项，不把跳过算通过。隐藏子进程入口由父测试启动，不批量执行全部 ignored 测试。

冷缓存超时、热缓存成功和媒体资源缺失是不同观察。重试不能覆盖第一次失败；注册或帮助输出也不能证明业务成功。
