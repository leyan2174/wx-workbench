## 限制

- 未验证真实微信版本、实际账号迁移、真实模型推理、跨 Windows 用户/机器迁移或真实云服务。
- 部分符号链接用例因 Windows 创建权限而忽略；目录联接和硬链接另有实际测试。
- DPAPI 不隔离同一 Windows 用户的进程。旧文件不能证明独占归属时保留，清理报告明确表示未完成。
- 强制终止整个 worker 不执行 Rust 析构，不能保证自动删除所有遗留临时文件；进程回收不等于文件事务回滚。
- 后台重启保留 `interrupted` 语义，不提供自动断点续跑。
