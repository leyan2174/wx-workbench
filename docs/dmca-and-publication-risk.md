# 来源与分发边界

三项主要代码来源、依赖版权、许可证文本及尚未确认的授权证据集中在[第三方说明](../THIRD_PARTY_NOTICES.md)。项目名称与 AI 作者声明不改变这些归属，原创部分的许可证也不替代第三方材料所需的授权。

源码、二进制、npm 包和独立机制文档分别检查分发内容与权利依据。未知分发权利的资产不能因仅供本地加载就自动获得随包分发许可；未随仓库提供的运行资产须在对应模块说明中明确。

发布范围包括候选文件及计划公开的 Git 历史。不得包含真实数据库、聊天记录、媒体、密钥、凭据或私人日志；`.gitignore` 和一次模式扫描不能代替内容检查。

独立机制文档不镜像未知许可的源码或二进制，引用保留来源，并区分观察事实、实现行为与未验证推断。账号授权、下载、上传、重启与写入边界见[工作流条件](workflow-requirements.md)。
