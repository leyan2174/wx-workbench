# 业务边界迁移阶段验收

验证日期：2026-09-15。基线为 `94ef925`。本记录对应公共契约和首批业务切片，不是整仓重构完成声明。

## 本阶段范围

| 部分 | 实际变化 |
| --- | --- |
| 公共契约 | service 拥有 Operation 请求、MCP Call 与 HostSettings；CLI 解析类型通过显式字段转换生成请求，执行模块消费契约。 |
| 联系人、群与标签 | 业务模型与窄来源接口独立；微信适配器负责 SQL、字段、标签 BLOB、成员关联。普通联系人继续使用固定名称快照，丰富联系人保留原兼容配置。标签成员选择直接调用业务用例。 |
| 朋友圈 | 查询、通知和旧导出复用适配器与作者策略；响应保留字段并补充本地缓存范围、截断、分页、无法读取记录及作者冲突数量。同名作者筛选拒绝歧义。 |
| 收藏 | CLI 与既有查询 RPC 接入业务模型和真实适配器；增加 `favorite_id`、`has_more`，修正秒与毫秒混存排序。没有新增 Web/MCP 收藏权限或入口。 |
| 结构化预览 | 模型迁入 business，微信 XML 解析迁入适配器，历史与新消息查询负责 JSON 投影；原富内容字段与普通摘要回退兼容。 |

旧富内容解析文件、已替代的联系人/SNS SQL 和解析实现，以及无人使用的查询辅助函数已移除。联系人适配器采用普通目录模块，不为夹具在生产代码中增加路径映射。

查询、前台操作和持久任务仍是不同生命周期。未新增任务队列、任务数据库、worker 或服务启动器。前一阶段的 DPAPI 密钥存储、配置固定、缓存代际和进程监督保持原调用通道；本阶段未改变获取算法或宿主授权边界。

## 限制与后续范围

- 独立 `mcp-voice-host-security` 的不限定目标测试命令，因夹具未声明生产进程模块单元测试所需的 `frida` 依赖而编译失败。专用 `--test audit` 已通过；对应进程单元测试在主仓库通过。未通过删除测试或功能制造通过结果。
- 主编译仍有 6 条非阻断告警，包括当前投影未消费的业务字段/状态，以及已有的未用导入和测试辅助方法；本记录不称其为零告警构建。
- 符号链接特权、实际外部模型/原生 FFmpeg 等原有忽略项未被宣传为已验证；人工密钥和合成格式不能替代真实版本兼容性证据。
- 会话、消息清单、历史搜索、完整通话事件用例、严格媒体关联、公众号文章、表情及跨域归档编排仍需完整迁移。共享格式助手仍有后续归属工作。
- 本地朋友圈结果不代表远端完整历史；通话事件不代表通话录音；启发式媒体推导不等于严格关联；重启后 `interrupted` 不代表自动断点续跑。
