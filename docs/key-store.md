# 账号密钥存储

Windows 使用账号绑定、当前用户 DPAPI 加密的统一存储，管理账号密钥、逐库密钥和图片 AES/XOR 材料。普通配置只新增 `key_store` 路径引用，不写入新的明文密钥。

DPAPI 保护落盘数据，不隔离同一 Windows 用户运行的进程；原有宿主授权、路径检查和私有文件权限仍然适用。更换 Windows 用户或无法解密时明确失败，不回退旧文件。

## 显式迁移

先通过 `WX_CLI_CONFIG` 选定账号配置，再执行：

```powershell
wx migrate-keys --cleanup-legacy
```

入口复用现有 daemon operation worker，只读取选定账号的本地资料，不扫描内存、不重启微信、不上传。普通查询不会迁移、删除旧文件或回退明文。

- 逐库密钥复用本地加密数据库页验证。没有数据库证据时，必须同时具备旧材料的明确账号绑定和 `--allow-unverified`。
- 图片材料区分缺少验证证据和已有证据不匹配。缺少证据或仅有 XOR 材料时需显式 `--allow-unverified`；已有证据不匹配时，该选项不能绕过拒绝。
- 未验证材料在结果中单独计数，不报告为已验证。重复字段、格式错误、账号不符和材料冲突均拒绝；损坏的新存储不会被重试覆盖。
- 有旧图片字段时必须使用 `--cleanup-legacy`，避免发布配置时再次生成明文临时副本。

迁移先写入加密材料并重新读取验证，再切换配置引用。两个文件的发布不是整体事务；若在中间失败，重复同一显式迁移即可继续。相同材料的重复导入不增加密钥版本，已有相对引用不被改写，无关配置字段保留。

清理选项移除选定配置中的旧图片字段。不能证明独占归属的旧逐库文件、账号文件仍然保留，结果明确报告 `exclusivity_not_established`；这表示清理尚未完成，不会生成明文镜像或备份。普通删除也不代表 SSD、备份或同步服务中的物理安全擦除。

## 身份与更新

`keys_file` 配置字段继续作为既有运行身份锚点，迁移时不要改名或删除该字段。新存储启用后它不再是业务密钥读取入口，但运行身份算法不变，任务历史不会因 `key_store` 引用而换命名空间。

首次切换存储引用会改变配置版本。应显式停止对应旧后台并重新连接 MCP/Web 会话：

```powershell
wx daemon stop
```

普通类型化更新锁定加密存储，读取当前版本并原子发布新记录；可选预期版本拒绝过期写入。数据库更新替换该类型的完整清单，账号、图片更新保留其他类型；迁移只合并不冲突的材料。临时文件仅含密文，发布前限制权限。

MCP 长期固定账号与配置身份，但只在每次操作期间持有阻止配置写入的锁。合法同账号密钥更新不改变配置指纹；配置文件替换、账号路径变化和存储引用变化均被拒绝。图片更新不再临时解锁或写回配置。

daemon 查询缓存记录密钥版本，后续请求发现更新后等待已有租约释放并刷新缓存；不会持有自己的查询读锁再等待失效写锁。

快照和临时缓冲区尽量清理密钥材料，不宣称消除了编译器、库或操作系统中的全部内存副本。密钥值不进入 `Debug`、迁移报告或任务结果。

## 既有后台任务

MCP 任务工具继续通过 service client 和已有任务 RPC 进入 daemon，再由现有 worker 执行。没有 MCP 自建队列、历史数据库、worker 或启动器。查询工具保持查询，同步语音工具没有改成后台任务。

提交被接受后，任务归 daemon 管理。MCP 断连、工具调用取消和响应超时不隐式取消任务；只有明确的任务取消调用才进入 daemon 取消流程。响应丢失或结果不确定时，重试必须使用同一幂等键，再读取返回的任务标识。

后台重启仍将未完成任务按现有规则标为 `interrupted`，不是自动断点续跑。
