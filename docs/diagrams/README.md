# 架构图

系统的入口、运行身份、任务生命周期和媒体处理边界见[架构说明](../architecture.md)及[业务入口与运行边界](../daemon-entrypoints.md)。这些文档是维护架构图时的依据。

当前分层图与运行图的 Mermaid 源码直接维护在[架构说明](../architecture.md)中。旧图件已清理；本目录的历史资料不作为当前运行架构依据。需要新增架构图时，以当前正文和实际调用链为依据，明确输入、生成方法与核验范围，再提交图源及必要的输出文件。不使用固定旧图号推断主题，也不能把渲染成功当作业务测试通过。

## 核对内容

- CLI、MCP 与 Web 的业务执行应指向 daemon；持久任务、前台租约与请求级执行须分别表示。
- 配置、账号身份、查询快照与宿主授权的归属应与源码一致。
- 图片、音频、ASR 和 SNS 图应显示读取、发布、取消及显式联网边界。
- 图中文字、箭头和节点不能重叠；既检查原始尺寸，也检查适合阅读的缩放视图。
- 公开图件不得含个人目录、账号、令牌、密钥或测试原始输出。

渲染结果与生产回归分别验证。当前测试入口见[测试说明](../../tests/README.md)；渲染报告只说明图件检查结果，不证明账号数据、媒体内容或模型效果正确。
