# 文档维护

- 根 README 说明安装、命令、配置和使用限制；[架构](architecture.md)说明模块职责与运行路径。
- `docs/` 保存当前功能与契约；`src/` 的模块文档解释协议、材料、输出发布和失败边界；测试入口见[测试说明](../tests/README.md)。
- 修改命令或契约时同步导航、示例、本地链接和 Mermaid 图源。图与正文均应对应实际调用链。
- 来源、许可证和版权归属见[第三方说明](../THIRD_PARTY_NOTICES.md)，不因改名或整理而删除。
- 过程记录、执行日志和检查报告保存到仓库外。功能说明不嵌入某轮测试数字，也不把合成测试通过等同真实账号、媒体质量或云服务验证。
- 原创文档由 AI 撰写，第三方引用保持原有归属。

维护时检查 Markdown 本地目标、标题锚点、代码围栏和命令路径。渲染检查与运行测试分别执行，不能相互替代。
