# 附件查询与发布契约

附件操作固定在已选择的账号内。查询、原件引用、解码发布和自动下载是不同能力，不能根据一个操作成功推断其他操作已经获得授权。MCP 参数和宿主设置见[协议说明](../src/mcp/PROTOCOL.md)。

## 消息定位

`daemon/query/strict_message.rs` 使用完整消息分片清单，按联系人、消息 local_id 和可选 create_time 定位唯一消息。同表重复和跨分片重复都拒绝；未知分片、同名视图、虚拟表和无 rowid 表不作为有效消息来源。文件与转发记录要求 local_id 为正数，create_time 默认 0 表示不限制时间，仍须唯一匹配。

存储消息有 1 MiB 上限；文件 XML 解码后最多 20,000 字节，转发记录最多 500,000 字节。拒绝非法 UTF-8、DTD、实体声明和不安全结构。`item_index` 是完整 datalist 中直接 dataitem 的零基索引，不受聊天展示页的项目截断影响。

## 原件引用

`decode_file_message` 只查当前账号的 `msg/file`；`decode_record_item` 只查对应联系人的 Rec 目录。根目录由账号数据库配置推导，工具参数不能指定其他账号目录。普通文本及只有元数据的项目不扫描磁盘。

成功返回 `exit_code=0`，以 `status` 区分 `found`、`missing`、`text` 和 `metadata_only`，并提供 `metadata` 和可选 `reference`。引用可包含路径、实际大小、MD5、绑定方式、警告和等价副本数量。

- 消息提供 MD5 时，候选必须读取并匹配摘要；不匹配是错误，不降级为无摘要查找。
- 没有消息 MD5 时，只接受唯一候选，并标明 `binding=heuristic` 及警告。计算出的文件摘要不会把启发式关联升级为已认证身份。
- 同摘要多副本可报告数量；无摘要多候选拒绝，不按时间或遍历顺序任取。
- 扫描条目、目录、候选、文件大小和累计哈希读取均有预算；预算耗尽不是“未找到”。

路径检查拒绝链接、重解析点及越界访问，并用只读句柄固定候选。句柄保持到 JSON 值构造完成，不覆盖后续 IPC 传输；返回路径不是永久锁或不可变副本。MD5 是内容比对手段，不是来源认证或数字签名。

这些工具不复制、解码、下载、上传或修改原始附件。daemon 为查询维护私有解密缓存，不属于修改原件。

## 图片

图片列表可请求资源元数据，字段投影由 MCP 协议限制。资源 MD5 和加密 DAT 大小不等于明文图片摘要与大小；缺失、不可用和歧义必须用状态表示，不能补零或任取一条。

图片列表和解码使用 `ResourceSnapshot`，通过 SQLite backup 将正常缓存的逻辑内容复制到账号私有目录中的临时静态资源库，再交给严格读取器。只转换副本的日志模式，不删除源 WAL 或修改源缓存日志模式；失败和作用域结束时清理副本。这允许正常缓存更新，同时保留底层静态资源检查。

`decode_image` 由 daemon 在宿主授权范围内执行。必须提供已存在的可信输出根，可选显式图片密钥文件；没有自动取钥、下载或外部转换器回退。唯一消息、资源关联、候选及路径守卫都通过后，才解码并以同目录临时文件发布。已有目标不覆盖。

图片文件发布与响应传输不是同一事务。发布后超时、响应超限或连接断开，文件仍可能保留；调用方应先检查目标，不能把失败当作“未执行”，也不能假定重试必然成功。

## 原始语音

`get_voice_messages` 只返回语音目录元数据；`wx voices` 提供原始 SILK 导出，保留已有 `0x02` 前缀，不转 WAV/MP3。完整聊天目录保留语音引用，并生成 `_voice_manifest.json`（`version: 1`、`items`）；`voices` 的条目位于 `_voice_export_summary.json` 的 `manifest`。

`message_id` 仅由精确会话和非零服务端消息 ID 组成，与独立的 `account_id` 一起使用，不以媒体 ID、消息 local_id 或 rowid 替代。未知发送者和时长为 null；严格关联后的 timestamp 为消息时间，未关联时间仅作媒体证据。文件成功不等于关联成功，`voices` 对未证明关联的条目仍计入 `incomplete_items`、标记 `partial` 并非零退出。

关联依赖完整来源和可核对的消息、媒体证据；缺失、重复或时间冲突不得伪装成成功。详见[数据库媒体契约](../src/adapters/wechat/media/VOICE_DATABASE.md)与[原始语音导出](../src/business/VOICE_EXPORT.md)。

## 富消息与其他入口

富消息解析返回有界结构化内容，本身不访问 CDN 或解码媒体。Web 自动图片、导出和 MCP 分别执行自己的授权与发布流程，不能复用旧提取接口来绕过受控路径。

## 测试

按[测试说明](../tests/README.md)运行定向回归。合成测试应覆盖唯一定位、同号跨分片、XML 预算、嵌套摘要、路径与链接拒绝、候选歧义、源文件字节不变，以及发布后响应失败。真实账号、私人附件或云上传须单独授权；合成通过不代替内容和版本兼容性验证。
