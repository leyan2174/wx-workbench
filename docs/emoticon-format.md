# 远端表情格式

`adapters/wechat/emoticons/remote_format.rs` 负责 AES-CBC、去填充、媒体标记与 HEVC 起点识别。`application/emoticons/download.rs` 负责下载、URL 回退、超时与大小限制、FFmpeg 监督、输出保护和发布。格式适配器不授予网络或写入权限。

密钥必须为 16 字节，IV 等于密钥。六种 ASCII 空白仅能位于完整十六进制字节之间；24/32 字节密钥和非整块密文被拒绝。空密文可恢复为空，但下载工作流将不足四字节的结果报告为不可用且不发布。

只剥离长度 1..16 且尾字节全部相等的填充，其他尾部原样保留。这是媒体格式兼容规则，不是严格 PKCS#7 验证。CBC 不提供认证；长度正确但密钥错误不一定报错，扩展名识别和 MD5 文件名也不能证明真实性。

HEVC 标记只检查前 256 字节，流起点优先 VPS，即使 SPS 更早。切片提取不执行帧解码；实际转换由受监督的 FFmpeg 进程执行。

合成回归覆盖固定密文向量、全部 1..16 填充、全填充结果、坏密文与空结果不发布。执行方式见[质量检查](quality-checks.md)，检查通过不代表私人媒体或所有微信版本兼容。
